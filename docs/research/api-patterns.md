# Research report: implementing an "Isaac" character + Isaac-mode in Enter the Gungeon (BepInEx + Alexandria), as of Oct 2026

Method: this note is based on reading the current Alexandria source (v0.5.10, last commit 2026‑08‑16), ModTheGungeonAPI (v1.9.x), the decompiled ETG `Assembly-CSharp` scripts (fedes1to/EtG-source dump), and several open-source mods (GungeonCraft, Modular, OMITB, Jolly Coop, BetterShop, Planetside, enter-the-beyond), plus the MTG modding gitbook. ## 1. Custom playable character — Alexandria `CharacterAPI` (namespace `Alexandria.CharacterAPI`)

Kyle's old "Custom Characters Mod" was merged into Alexandria as CharApi; the entry point is `Loader` ([CharApi/CharacterBuilding/Loader.cs](https://github.com/Nevernamed22/Alexandria/blob/master/CharApi/CharacterBuilding/Loader.cs)). **[verified]**

### 1.1 Entry points
```csharp
// PNG-folder based (API packs sprites at runtime):
CustomCharacterData Loader.BuildCharacter(string filePath, string guid, Vector3 foyerPos, bool hasAltSkin, Vector3 altSwapperPos,
    bool removeFoyerExtras = true, bool hasArmourlessAnimations = false, bool usesArmourNotHealth = false, bool paradoxUsesSprites = true,
    bool useGlow = false, GlowMatDoer glowVars = null, GlowMatDoer altGlowVars = null, int metaCost = 0, bool hasCustomPast = false, string customPast = "")
// Prebaked tk2d collection + animation (from a Unity 2017.4 asset bundle):
CustomCharacterData Loader.BuildCharacterBundle(string filePath, tk2dSpriteCollectionData d1, tk2dSpriteAnimation anim1, tk2dSpriteCollectionData d2, tk2dSpriteAnimation anim2, string guid, Vector3 foyerPos, bool hasAltSkin, Vector3 altSwapperPos, ... same flags ..., Texture2D BossCard = null)
```
- `filePath` is an **embedded-resource folder path** inside your DLL, e.g. `"MyMod/Characters/Isaac"` (slashes converted to dots). It must contain `characterdata.txt` plus optional sub-folders.
- `guid` is used for `ETGModCompatibility.ExtendEnum<PlayableCharacters>(guid, data.nameShort)` → your **new `PlayableCharacters` enum value** (`data.identity`). Vanilla enum ends at `Gunslinger`(10); Alexandria treats any `characterIdentity > PlayableCharacters.Gunslinger` as custom (`IsCustomCharacter()` in CharApiHooks.cs L302).
- Real-world calls: OMITB `Loader.BuildCharacter("NevernamedsItems/Characters/Shade", "nevernamed.etg.omitb", new Vector3(12.3f,21.3f), false, new Vector3(13.1f,19.1f), false,false,true,true,false,null,null,0,false,"")` ([OMITB Class1.cs](https://github.com/Nevernamed22/OnceMoreIntoTheBreach/blob/master/MakingAnItem/Class1.cs)); Modular uses `BuildCharacterBundle(...)` with an asset-bundle collection + glow + custom past ([Modular Module.cs ~L232](https://github.com/Some-Bunny/Modular/blob/master/Module.cs)); enter-the-beyond has a commented full example incl. `Loader.SetupCustomBreachAnimation`, `Loader.AddPhase(name, new CharacterSelectIdlePhase{...})`, `Loader.AddCoopBlankOverride(name, Func<PlayerController,float>)` ([-EXAMPLEPLEASELOOKATTHISFFS.cs](https://github.com/bobot-dev/enter-the-beyond/blob/main/Character%20Api/-EXAMPLEPLEASELOOKATTHISFFS.cs)). Other CharApi users found via code search: Skilotar/Knife_to_a_Gunfight (`Scripts/Characters/Charinit.cs`), Neighborin0/FrostAndGunfire, DainPLay/RPGworld-mod (`InitialiseCharacters.cs`), UnstableStrafe/ChildrenOfKaliber, qaday123/Blammco-Catalogue, bogdanovicii/pluto-the-cat.

### 1.2 `characterdata.txt` format (parsed by `Loader.ParseCharacterData`) **[verified]**
```
base: pilot            # which vanilla prefab to clone: pilot|convict|robot|marine(=Soldier)|hunter(=Guide)|bullet|paradox(=Eevee)|gunslinger ; robot forces armor 6
name: Isaac
name short: Isaac      # becomes nameShort; internal prefab name = "Player" + nameShort  → "PlayerIsaac"
nickname: The Child
armor: 0
punchout sprite fix: true
<loadout>
isaacmod:isaac_tears infinite      # console IDs from Gungeon.Game.Items; "infinite" flag only valid for guns
isaacmod:some_passive
</loadout>
<altguns>                          # alt starter gun(s) used by alt costume
</altguns>
<stats>
health: 3                          # PlayerStats.StatType names, case-insensitive; written via player.stats.SetBaseStatValue
movementspeed: 7
</stats>
```
Lines starting `#` are comments. Loadout items are resolved via `Gungeon.Game.Items[id]` (so your custom gun must be registered *before* `BuildCharacter`). Infinite guns get `InfiniteAmmo/PersistsOnDeath/CanBeDropped=false/PreventStartingOwnerFromDropping` enforced on the prefab at run start and restored on character clear ([CustomCharacter.cs](https://github.com/Nevernamed22/Alexandria/blob/master/CharApi/CharacterBuilding/CustomCharacter.cs), `Hooks.ResetInfiniteGuns`).

### 1.3 Resource folders auto-detected under `filePath` (Loader.GetCharacterData) **[verified]**
| folder/file | purpose |
|---|---|
| `sprites/` | loose PNGs whose **names match the base character's tk2d sprite definition names** (e.g. `rogue_idle_001`); replaced one-by-one via `RuntimeAtlasPage` (`SpriteHandler.HandleAnimationSprites`). Size can differ from original (bounds recomputed as `px/16`). |
| `playersheet.png` | alternative: a full replacement sheet with identical layout to the base atlas. |
| `newspritesetup/` (`pathForSprites`) | **fully custom animation set**: one sub-folder per animation named exactly like the entries in `SpriteHandler.playerAnimInfo` (`idle`, `idle_bw`, `idle_forward`, `idle_hand`, `idle_twohands`, `run_down`, `run_right`, `run_up`, `run_right_bw`, `dodge`, `dodge_bw`, `dodge_left`, `dodge_left_bw`, `death`, `death_coop`, `death_shot`, `doorway`, `item_get`, `pitfall`, `pitfall_down`, `pitfall_return`, `slide_*`, `spinfall`, `ghost_idle_*`, `ghost_sneeze_*`, `jetpack_*`, `pet`, `tablekick*`, `chest_recover`, `select_idle`, `select_choose`, …; `_hand`/`_twohands` variants; `custom/<name>` and `breach_idles/<name>` for extra clips). Each sub-folder's PNGs become frames; `hand_001.png` is the hand sprite (set to 4×4 units quad). FPS/wrap mode come from `playerAnimInfo` (e.g. idle Loop 6fps, run Loop 9fps, dodge Once 12fps). `_armorless` suffix folders are supported (`hasArmourlessAnimations`). |
| `newaltspritesetup/`, `alt_sprites/`, `alt_playersheet` | same for the alternate costume. |
| `foyercard/` | breach select stand overhead card textures. |
| `loadoutsprites/` | loadout icons shown on the select card. |
| `punchout/` (`facecard1/2/3`) and `punchout.sprites/` | Resourceful Rat punch-out minigame sprites; names `<nameshort>_punch_<anim>_00N` with anims `idle, punch_left/right, punch_blocked_*, miss_*, hit_*, star, dodge_*, block, block_hit, duck, exhaust, knockout, win` (`punchoutPlayerAnimInfo`). GungeonCraft also sets these up manually ([CwaffCharacterCore.cs `SetupPunchoutSprites`](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Characters/CwaffCharacterCore.cs)). |
| loose: `icon.png` (minimap), `facecard.png` (HUD portrait), `bosscard_*.png` (boss intro card, 115×71 noted by GungeonCraft for win pic), `win_pic.png`, `win_pic_junkan.png`, `coop_page_death.png`, `alt_skin_obj_sprite_001/002.png` (costume swapper objects in the breach) | |

### 1.4 What `CharacterBuilder.BuildCharacter` does **[verified]** ([CharacterBuilder.cs](https://github.com/Nevernamed22/Alexandria/blob/master/CharApi/CharacterBuilding/CharacterBuilder.cs))
Instantiates `BraveResources.Load("player"+rogue|convict|robot|marine|guide|bullet|eevee|gunslinger)`, adds `CustomCharacter` component, sets `AllowZeroHealthState/ForceZeroHealthState = usesArmourNotHealth`, `hasArmorlessAnimations`, `altHandName="hand_alt"`, then `SpriteHandler.HandleSprites`, `HandleLoadout` (clears `startingGunIds/startingPassiveItemIds/startingActiveItemIds/startingAlternateGunIds` and refills), `HandleStats`, `healthHaver.ForceSetCurrentHealth(data.health)`, `Armor`, `characterIdentity = data.identity`, string keys `#PLAYER_NAME_<IDENTITY>`, `#PLAYER_NICK_<IDENTITY>`, `#CHAR_<NAMESHORT>`, `#CHAR_<NAMESHORT>_SHORT` (StringHandler writes into `StringTableManager.m_coreTable`), registers for punch-out, `FakePrefab.MarkAsFakePrefab`, stores in `CharacterBuilder.storedCharacters[nameInternal.ToLower()] = (data, prefab)`, and adds to `ETGModConsole.Characters` so `character isaac` works in the F2 console. Breach stand: `FoyerCharacterHandler.AddCustomCharactersToFoyer` clones the base character's `FoyerCharacterSelectFlag`, sets `prerequisites = data.prerequisites` (`DungeonPrerequisite[]`, default empty = always unlocked), `CharacterPrefabPath`, idle doer phases, overhead card, PlayMaker `ChangeToNewCharacter.PlayerPrefabPath`, and builds a costume swapper if alt sprites exist.
- Save/mid-game save: `Hooks.MidGameSaveDataGetPlayerOnePrefabPatch` resolves custom identities for the elevator save ([CharApiHooks.cs L516](https://github.com/Nevernamed22/Alexandria/blob/master/CharApi/Tools/CharApiHooks.cs)). Unlocks: use `data.prerequisites` with SaveAPI's `CustomDungeonPrerequisite`/`CustomDungeonFlags` (SpecialAPI/SaveAPI, vendored by Modular, GungeonCraft `src/GungoSaveAPI`, Planetside).
- Alternative "manual" route (GungeonCraft): build `CustomCharacterData` in code and call `CharacterBuilder.GetPlayerPrefab`, `CharacterBuilder.CustomizeCharacterNoSprites(...)`, then add to `storedCharacters` yourself ([Rancher.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Characters/Rancher/Rancher.cs) + CwaffCharacterCore.cs). Rancher also shows `pc.ForceHandless`, `pc.gunAttachPoint.localPosition`, per-clip audio events (`Play_Leap`, `Play_Roll`, `Play_Fall`, `Play_Respawn`), and `stats = { RateOfFire 0.5, ChargeAmountMultiplier 0.5, ReloadSpeed 2, Accuracy 2 }`.
- Voice: CharApi assigns `Play_CHR_fool_voice_01` to `pet` frames; other voices are wwise events on animation frames (`frame.eventAudio`, `triggerEvent`).
- Reference docs: Thunderstore page lists CharacterAPI features ([Alexandria on Thunderstore](https://thunderstore.io/c/enter-the-gungeon/p/Alexandria/Alexandria/)); the gitbook's character page only embeds a Google Doc that could not be fetched during research (see gaps): https://mtgmodders.gitbook.io/etg-modding-guide/custom-characters/creating-a-standalone-custom-character .

## 2. A "gun" that is actually tears + locking the player out of other guns

### 2.1 Building the tear gun (ItemAPI + MTG API) **[verified]**
- `ItemBuilder.BuildGun<T>(name, prefix, spriteName, shortDesc, longDesc, idleFps, shootFps, reloadFps, quality, gunIdToCopyModuleFrom, shootStyle, projectile, reloadTime, coolDown, spread, clipSize, maxAmmo, barrelOffset, gunClass, gunHandedness)` where `T : GunBehaviour` ([ItemBuilder.cs L210-330](https://github.com/Nevernamed22/Alexandria/blob/master/ItemAPI/ItemBuilder.cs)). Internally: `ETGMod.Databases.Items.NewGun(name, spriteName)` (clones Pea Shooter, fresh `RawSourceVolley`, 300 ammo, console id `outdated_gun_mods:<name>` → renamed to `<prefix>:<name>`), `GunExt.SetupSprite(gun, null, spriteName+"_idle_001", fps)`, `gun.AddProjectileModuleFrom(Gun)` (clones the module and its projectile list), then `ETGMod.Databases.Items.Add(gun, false, "ANY")`.
- MTG API extension methods ([GunExt.cs](https://github.com/SpecialAPI/ModTheGungeonAPI/blob/master/ModTheGungeonAPI/ETGMod/Extensions/GunExt.cs)): `gun.AddProjectileFrom(Gun|string)`, `gun.AddProjectile(Projectile)`, `gun.AddProjectileModuleFrom(Gun|string)`, `gun.SetAnimationFPS`, `gun.UpdateAnimations`, `gun.SetupSprite`. `GunBehaviour` virtual hooks ([GunBehaviour.cs](https://github.com/SpecialAPI/ModTheGungeonAPI/blob/master/ModTheGungeonAPI/ETGMod/GunBehaviour.cs)): `OnPlayerPickup`, `OnPostFired`, `PostProcessProjectile`, `OnPreFireProjectileModifier(Gun, Projectile, ProjectileModule)`, `OwnedUpdatePlayer`, `OnSwitchedToPlayer/AwayFromPlayer`, `CanCollectAmmoPickup(..., ref bool canCollect, ref bool displayAmmoFullMessage)`, `ModifyClipCount`, `AutoreloadOnEmptyClip`, `MidGameSerialize/Deserialize`, etc. Alexandria also offers `AdvancedGunBehavior` ([ItemAPI/AdvancedClasses/AdvancedGunBehaviour.cs](https://github.com/Nevernamed22/Alexandria/blob/master/ItemAPI/AdvancedClasses/AdvancedGunBehaviour.cs)).
- Projectile: `ItemBuilder.BuildProjectile(int baseProjId, string spriteName, IntVector2 spriteSize, bool rotate, float damage, speed, force, range)` or manual: `Projectile p = UnityEngine.Object.Instantiate((PickupObjectDatabase.GetById(86) as Gun).DefaultModule.projectiles[0]); p.gameObject.SetActive(false); FakePrefab.MarkAsFakePrefab(p.gameObject); DontDestroyOnLoad(p);` then `p.baseData.damage/speed/range/force`, `p.AdditionalScaleMultiplier`, `p.ignoreDamageCaps`, `p.pierceMinorBreakables`, `p.shouldRotate`, `p.SetProjectileSpriteRight("tear", w, h, lightened, anchor, colliderW, colliderH)` (Alexandria `GunTools.SetProjectileSpriteRight`), `p.hitEffects` copy from vanilla (`ProjectileImpactVFXPool` fields `alwaysUseMidair, overrideMidairDeathVFX, tileMapHorizontal/Vertical, enemy, midairInheritsRotation/Flip`), `gun.AddCustomMuzzleflash(...)`. Guides: [setting-up-projectiles](https://mtgmodders.gitbook.io/etg-modding-guide/making-a-gun/setting-up-projectiles), [hiteffects](https://mtgmodders.gitbook.io/etg-modding-guide/making-a-gun/setting-up-projectiles/projectile-hiteffects), [adding components](https://mtgmodders.gitbook.io/etg-modding-guide/making-a-gun/setting-up-projectiles/adding-components-to-a-projectile).
- Isaac-style modifiers = vanilla components on the projectile (decompiled fields verified): `BounceProjModifier { numberOfBounces, damageMultiplierOnBounce, bouncesTrackEnemies, bounceTrackRadius, TrackEnemyChance, percentVelocityToLoseOnBounce, OnBounce }`, `PierceProjModifier { penetration, penetratesBreakables, MaxBossImpacts }`, `HomingModifier { HomingRadius=2, AngularVelocity=180 }`; add with `proj.gameObject.GetOrAddComponent<T>()`. For Isaac's lob/arc you'd use `Projectile.ModifyVelocity` / `PreMoveModifiers` / `OnPostUpdate` events or a custom `MonoBehaviour` (Alexandria has `ProjectileUtility.ConvertToHelixMotion`, `InstantiateAndFireInDirection`, `ProjectileExt`).
- Fire modes: `ProjectileModule.ShootStyle { SemiAutomatic, Automatic, Beam, Charged, Burst }`, `cooldownTime`, `numberOfShotsInClip (-1 = no clip)`, `angleVariance`, `ammoCost`, `chargeProjectiles` (list of `ChargeProjectile{ChargeTime, Projectile}`), `ammoType` / `customAmmoType` (see [gun-ammo-types](https://mtgmodders.gitbook.io/etg-modding-guide/making-a-gun/gun-ammo-types)). Fire rate scales with `StatType.RateOfFire`, damage with `Damage`, speed with `ProjectileSpeed`, range with `RangeMultiplier`, size with `PlayerBulletScale`, bounces/pierce with `AdditionalShotBounces`/`AdditionalShotPiercing` (via `PlayerStats.RebuildGunVolleys`) — so Isaac stats map cleanly onto `PlayerStats.StatType`.
- Infinite / undroppable starter: `gun.InfiniteAmmo = true` (sets `LocalInfiniteAmmo`; `AdjustedMaxAmmo` becomes `int.MaxValue`), `gun.CanBeDropped = false`, `gun.PreventStartingOwnerFromDropping = true`, `gun.PersistsOnDeath = true`, `gun.quality = ItemQuality.EXCLUDED` (so it is never rolled as loot; note `RewardManager.GetItemForPlayer` additionally skips guns with `InfiniteAmmo && !CanBeDropped && quality==SPECIAL`). GungeonCraft's Vacpack does exactly this: `quality: EXCLUDED, infiniteAmmo: true, undroppableStarter: true, isStarterGun: false, preventVolleyModifications: true` ([Vacpack.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Guns/Vacpack.cs)). CharApi's `infinite` loadout flag does the same at runtime.
- Hiding the gun sprite: no API; options **[inferred]**: give the gun 1×1 transparent `_idle_001` sprite (+ matching `.json/.jtk2d` hand points), set `gun.gunHandedness = GunHandedness.NoHanded`/`ForceHandless` on the player (Rancher toggles `pc.ForceHandless`), or disable the gun renderer in `OwnedUpdatePlayer`. Ammo HUD: hide/replace with Alexandria `CustomAmmoDisplay` (abstract `DoCustomAmmoDisplay(GameUIAmmoController)` component on the gun, [Misc/CustomAmmoDisplay.cs](https://github.com/Nevernamed22/Alexandria/blob/master/Misc/CustomAmmoDisplay.cs)) or custom clip art via `CustomClipAmmoTypeToolbox.AddCustomAmmoType(name, fgPath, bgPath)`.
- Gun `.json/.jtk2d` metadata: each animation frame needs hand/`Casing` attach points; coordinates are `pixels * 0.0625` from bottom-left; use **GAER** from [pcrain/gungeon-modding-tools](https://github.com/pcrain/gungeon-modding-tools/releases); `.json`→`.jtk2d` is a rename ([JsonToJtk2d](https://github.com/SpecialAPI/JsonToJtk2d), [MTG wiki](https://github.com/SpecialAPI/ModTheGungeonAPI/wiki/Converting-.json-files-to-.jtk2d-files)). Gun sprites are expected in embedded folders `sprites/WeaponCollection`, `sprites/ProjectileCollection`, `sprites/Ammonomicon Encounter Icon Collection` ([gitbook](https://mtgmodders.gitbook.io/etg-modding-guide/making-a-gun/making-the-gun/setting-up-gun-sprite-folders)); MTG API auto-loads them into `ETGMod.Databases.Items.WeaponCollection/ProjectileCollection`.

### 2.2 Locking the player to the tear gun **[verified in game source + mods]**
Pickup path in vanilla: `Gun.Pickup(PlayerController)` → `player.inventory.AddGunToInventory(this, true)` (or `player.ChangeToRandomGun()` if `CharacterUsesRandomGuns`) → `GunInventory.AddGunToInventory(Gun gun, bool makeActive)` → `CreateGunForAdd` → `ChangeGun`. Chest/boss/shop "give directly" paths use `LootEngine.GivePrefabToPlayer(GameObject, PlayerController)` / `TryGiveGunToPlayer`.
- **Existing no-gun character**: **Modular** (Some-Bunny/Modular, "cannot use any guns other than their starter weapon"). It patches `[HarmonyPatch(typeof(Gun), nameof(Gun.Pickup))]` prefix: if `player.IsModular()` it attaches a `ChooseModuleController` UI to the gun and `return false` (vanilla pickup never runs, gun stays on floor as a "module chooser"); `[HarmonyPatch(typeof(LootEngine), nameof(LootEngine.GivePrefabToPlayer))]` prefix handles the direct-give path; plus `PlayerStats.RebuildGunVolleys` and `GameUIRoot.UpdateGunDataInternal` patches for HUD ([Code/Hooks/Hooks.cs](https://github.com/Some-Bunny/Modular/blob/master/Code/Hooks/Hooks.cs), [ModularGunComponent.cs](https://github.com/Some-Bunny/Modular/blob/master/Code/Collectibles/Guns/ModularGunComponent.cs)). This is the best reference for "convert any gun pickup into an Isaac item choice".
- Other hook points: `GunInventory.AddGunToInventory` prefix/postfix (GungeonCraft uses both: [DisplayPedestal.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Passives/DisplayPedestal.cs), [CwaffMasteries.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Misc/CwaffMasteries.cs)); `GunInventory.GunLocked` is an `OverridableBool` — `player.inventory.GunLocked.SetOverride("isaac", true)` blocks `ChangeGun` (unless `overrideGunLock`) and `ChangeToRandomGun`; `GunInventory.maxGuns`; `PlayerController.IsGunLocked` (bool; blocks firing/aiming — not what you want); `PlayerController.AcquirePassiveItemPrefabDirectly(PassiveItem)` instantiates a prefab, suppresses notification/VFX and calls `Pickup` — useful to silently grant Isaac items. For a cleaner approach than per-pickup patches, remove guns at the loot-roll stage (Section 4) and keep a `Gun.Pickup` prefix as a safety net that swaps the gun for an Isaac item (e.g. `LootEngine.SpawnItem(isaacItem.gameObject, gun.transform.position, Vector2.zero, 0f)` then `Destroy(gun.gameObject)`).
- Detecting "player is Isaac": `player.characterIdentity == IsaacIdentity` (from `data.identity` / `ETGModCompatibility.ExtendEnum<PlayableCharacters>(GUID, "Isaac")` — calling ExtendEnum again with same args returns the cached value, per MTG wiki), or `player.GetComponent<CustomCharacter>()?.data == myData`, or `CharacterBuilder.storedCharacters["playerisaac"]`. Before the run starts, `GameManager.PlayerPrefabForNewGame` holds the selected prefab (GungeonCraft uses it for quickstart). Mod helper pattern: Modular's `PlayerHasCore()`/`IsModular()` extension ([Toolbox.cs](https://github.com/Some-Bunny/Modular/blob/master/Code/Toolboxes/Toolbox.cs)).

## 3. Custom items (PassiveItem / PlayerItem / pickups), stats, synergies

### 3.1 Core pattern (ItemAPI) **[verified]** — [ItemBuilder.cs](https://github.com/Nevernamed22/Alexandria/blob/master/ItemAPI/ItemBuilder.cs), gitbook [passive](https://mtgmodders.gitbook.io/etg-modding-guide/making-mods-setup/creating-a-passive) / [active](https://mtgmodders.gitbook.io/etg-modding-guide/making-mods-setup/creating-an-active)
```csharp
public class SadOnion : PassiveItem {
  public static void Init() {
    var item = ItemBuilder.BuildItem<SadOnion>("Sad Onion", "isaac", "IsaacMod/Resources/Items/sad_onion", "Tears up", "Isaac's tears fall faster...", PickupObject.ItemQuality.C);
    item.AddPassiveStatModifier(PlayerStats.StatType.RateOfFire, 1.3f, StatModifier.ModifyMethod.MULTIPLICATIVE);
    item.AddToSubShop(ItemBuilder.ShopType.Cursula); // optional sub-shop pool
  }
  public override void Pickup(PlayerController player){ base.Pickup(player); }
  public override DebrisObject Drop(PlayerController player){ return base.Drop(player); }
}
// Active: ItemBuilder.BuildItem<T>(name, prefix, spritePath, short, long, ItemBuilder.CooldownType.{Timed,Damage,PerRoom,None}, rechargeTime, consumable, quality); override DoEffect(PlayerController user), CanBeUsed(user).
```
`BuildItem` = `new GameObject` + `AddComponent<T>` + `ItemBuilder.AddSpriteToObject(name, resourcePath, obj)` (embedded PNG, `.png` auto-appended; path uses `/` → `.`) + `SetupItem(item, short, long, prefix)` which calls `ETGMod.Databases.Items.SetupItem` (adds `EncounterTrackable`, journal keys `#<NAME>_ENCNAME/_SHORTDESC/_LONGDESC`), `SpriteBuilder.AddToAmmonomicon`, `SetName/SetShortDescription/SetLongDescription` (writes `ETGMod.Databases.Strings.Items`), `Gungeon.Game.Items.Add("<prefix>:<name_with_underscores>", item)`, and `ETGMod.Databases.Items.Add(item)`. **Important:** `ItemDB.AddSpecific` assigns `PickupObjectId`, adds an `EncounterDatabaseEntry`, and **adds every new item to `RewardManager.ItemsLootTable` (or `GunsLootTable` for guns) with weight 1** and to `ModLootPerFloor["ANY"]` (merged into `Dungeon.baseChestContents` on `Dungeon.Start`) ([ItemDB.cs L87-160](https://github.com/SpecialAPI/ModTheGungeonAPI/blob/master/ModTheGungeonAPI/ETGMod/Databases/ItemDB.cs)). Consequence for your design: Isaac items will leak into normal runs unless you set `quality = ItemQuality.EXCLUDED` (never rolled) or remove them with Alexandria `LootUtility.RemovePickupFromLootTables(po)` and only serve them from your own `GenericLootTable` in Isaac mode.
- Quality enum (verified): `EXCLUDED=-100, SPECIAL=-50, COMMON=0, D=1, C=2, B=3, A=4, S=5`.
- Stat modifiers: `ItemBuilder.AddPassiveStatModifier(po, StatType, amount, ModifyMethod.ADDITIVE|MULTIPLICATIVE)` works on PassiveItem/PlayerItem/Gun (`passiveStatModifiers` arrays); `AddCurrentGunStatModifier` for "while held" gun stats; Alexandria **StatAPI** adds `ModifyMethodE.TrueMultiplicative/Exponent`, custom stats (`StatAPIManager.CreateCustomStatModifier(modPrefix, statName, amount, method)`, `po.AddPassiveCustomStatModifier(...)`, `baseStatValues`, hooks `PreCustomStatModification/AfterAdditive/...`) — use this for Isaac-only stats like **Luck** or **Tear Height** that have no vanilla StatType ([StatAPI/StatAPIManager.cs](https://github.com/Nevernamed22/Alexandria/blob/master/StatAPI/StatAPIManager.cs)). Timed buffs: `player.GetExtComp().DoTimedStatModifier(stat, amount, time, method)` ([ExtendedPlayerComponent.cs](https://github.com/Nevernamed22/Alexandria/blob/master/Misc/ExtendedPlayerComponent.cs)).
- Isaac→ETG stat mapping (vanilla `PlayerStats.StatType`, verified list): Damage→`Damage`; Tears→`RateOfFire`; Shot speed→`ProjectileSpeed`; Range→`RangeMultiplier`; Speed→`MovementSpeed`; Luck→`Coolness` (affects chest/drop chance) or a StatAPI custom stat; Devil-deal/curse→`Curse`; tear size→`PlayerBulletScale`; HP containers→`Health`; also `AdditionalShotPiercing`, `AdditionalShotBounces`, `KnockbackMultiplier`, `DamageToBosses`, `DodgeRollDistanceMultiplier`, `AdditionalBlanksPerFloor`, `MoneyMultiplierFromEnemies`, `GlobalPriceMultiplier`.
- Synergies: `CustomSynergies.Add(string name, List<string> mandatoryConsoleIDs, List<string> optionalConsoleIDs = null, bool affectedByLichesEye = true)` returns `AdvancedSynergyEntry` (appended to `GameManager.Instance.SynergyManager.synergies`; set `entry.statModifiers`/`bonusSynergies`); check with `player.PlayerHasActiveSynergy("name")` ([CustomSynergies.cs](https://github.com/Nevernamed22/Alexandria/blob/master/ItemAPI/SynergyTools/CustomSynergies.cs), [gitbook](https://mtgmodders.gitbook.io/etg-modding-guide/making-mods-setup/synergies)).
- Item tips on hover: `pickup.AddItemTip(text)` ([Integrations/ItemTipsIntegration.cs](https://github.com/Nevernamed22/Alexandria/blob/master/Integrations/ItemTipsIntegration.cs), soft-dep `glorfindel.etg.itemtips`).
- Pickups (hearts/keys/coins/bombs): vanilla classes are `HealthPickup : PickupObject, IPlayerInteractable { healAmount, armorAmount, healVFX, armorVFX }`, `KeyBulletPickup { numberKeyBullets, IsRatKey }`, `CurrencyPickup { currencyValue, IsMetaCurrency }`, `AmmoPickup { mode }`, `SilencerItem : PlayerItem` (blank). Cheapest route for Isaac hearts/keys/coins: clone the vanilla prefabs (`PickupObjectDatabase.GetById(...)`, e.g. `RewardManager.FullHeartIdPrefab/HalfHeartIdPrefab`) with `FakePrefab`, swap sprites via `SpriteBuilder.AddSpriteToCollection`, tweak fields; soul hearts need a new class (Section 5). Spawn with `LootEngine.SpawnItem(GameObject, Vector3 pos, Vector2 dir, float force, bool invalidUntilGrounded=true, bool doDefaultItemPoof=false, ...)` or `LootEngine.SpawnHealth(center, halfHearts, dir)`, `LootEngine.SpawnCurrency(center, amount)`. Pickup events: Alexandria `CustomActions.OnAnyPlayerCollectedHealth/Key/Blank/Ammo`, `OnAnyPlayerNudgedHealth` ([Misc/CustomActions.cs](https://github.com/Nevernamed22/Alexandria/blob/master/Misc/CustomActions.cs)). Existing vanilla pedestal items that are stat-only: `BasicStatPickup { modifiers, ArmorToGive, IsJunk, GivesCurrency }`.

## 4. Loot control for "Isaac mode" (vanilla pipeline + hook points)

### 4.1 How vanilla loot flows **[verified in decompiled source]**
- Master tables: `GameManager.Instance.RewardManager.GunsLootTable` and `.ItemsLootTable` (`GenericLootTable { defaultItemDrops: WeightedGameObjectCollection{elements: List<WeightedGameObject{pickupId, weight, rawGameObject, forceDuplicatesPossible, additionalPrerequisites}>}, includedLootTables, tablePrerequisites }`, `GetCompiledRawItems()`).
- Per-floor tuning: `RewardManager.CurrentRewardData` → `FloorRewardData { GunVersusItemPercentChance=0.5, D/C/B/A/S_Chest_Chance, *_RoomChest_Chance, *_BossGun_Chance, *_Shop_Chance, ReplaceFirstRewardWithPickup=0.2, SingleItemRewardTable, PercentOfRoomClearRewardsThatAreChests, ChestSystem_ChestChanceLowerBound/UpperBound/Increment, FloorChanceToDropAmmo ... }`.
- The central roll: `GameObject RewardManager.GetItemForPlayer(PlayerController player, GenericLootTable tableToUse, ItemQuality targetQuality, List<GameObject> excludedObjects, bool ignorePlayerTraits=false, System.Random safeRandom=null, bool bossStyle=false, List<GameObject> additionalExcludedObjects=null, bool forceSynergyCompletion=false, RewardSource rewardSource=UNSPECIFIED)` — walks `tableToUse.GetCompiledRawItems()`, filters by quality, prerequisites, excluded lists, gun-class modifiers, synergy multipliers, "already seen" differentiator, and returns a prefab GameObject; falls back a tier at a time ([RewardManager.cs L667](https://github.com/fedes1to/EtG-source/blob/master/ExportedProject/Assets/MonoScript/Assembly-CSharp/RewardManager.cs)).
- **Chests**: spawned by `RewardManager.SpawnRewardChestAt(pos, overrideGunVsItemChance=-1, excludedQuality)` / `SpawnRoomClearChestAt` → `SpawnInternal` sets `chest.lootTable.lootTable = (Random.value < gunVersusItemPercentChance) ? GunsLootTable : ItemsLootTable` (also `overrideItemLootTables[0]`). Contents are decided lazily: `Chest.DetermineContents(PlayerController, int tierShift=0)` (protected) → if `forceContentIds.Count>0` use those, else `GenerateContents` → `LootData.GetItemsForPlayer(player, tierShift, overrideTable, rng)` → `LootData.GetItemForPlayer(...)` (its own quality roll from `D/C/B/A/S_Chance`); `Chest.PredictContents(player)` just calls `DetermineContents`. Fields: `Chest.contents (List<PickupObject>)`, `forceContentIds (List<int>)`, `lootTable (LootData)`, `IsRainbowChest`. Opening → `PresentItem`/`SpewContentsOntoGround` → `LootEngine.SpewLoot`.
- **Room clear**: `RoomHandler.HandleRoomClearReward()` (public virtual): rolls `Coolness/100 - Curse/100` into chest chance, otherwise `SingleItemRewardTable` pickups (hearts/ammo via `FullHeartPrefab/HalfHeartPrefab`), chest via `SpawnRoomRewardChest`; floor boss → `HandleBossClearReward()` → picks from `Dungeon.sharedSettingsPrefab.ChestsForBosses` (a `RewardPedestal` or chest) ([Dungeonator/RoomHandler.cs](https://github.com/fedes1to/EtG-source/blob/master/ExportedProject/Assets/MonoScript/Assembly-CSharp/Dungeonator/RoomHandler.cs)).
- **Boss pedestal**: `RewardPedestal.DetermineContents(PlayerController)` (protected): `if (lootTable.lootTable != null) contents = lootTable.lootTable.SelectByWeightWithoutDuplicatesFullPrereqs(null)` else `GetRewardObjectBossStyle(player)` → gun with prob. from `IsBossRewardForcedGun()` (forces a gun if nobody got a new gun this floor — note `HasReceivedNewGunThisFloor`) else `GetRewardItemDaveStyle` from `ItemsLootTable`. Fields: `contents (PickupObject)`, `UsesSpecificItem/SpecificItemId`, `lootTable`, `IsBossRewardPedestal`.
- **Shops**: `BaseShopController.DoSetup()` (protected virtual): group 1 slots from the shop's own `shopItems` GenericLootTable via `SubshopSelectByWeightWithoutDuplicatesFullPrereqs`; group 2 slots: with `ReplaceFirstRewardWithPickup` chance a table item, otherwise `RewardManager.GetRewardObjectShopStyle(player, forceGun=false, forceItem=false, excluded)` which 50/50 picks `GunsLootTable` vs `ItemsLootTable` at `GetShopTargetQuality()`; each slot becomes a `ShopItemController` via `Initialize(PickupObject, BaseShopController|ShopController)` ([BaseShopController.cs L888](https://github.com/fedes1to/EtG-source/blob/master/ExportedProject/Assets/MonoScript/Assembly-CSharp/BaseShopController.cs)). Sub-shop tables are assets in `shared_auto_001`: `Shop_Key_Items_01` (Flynt), `Shop_Truck_Items_01` (Trorc), `Shop_Curse_Items_01` (Cursula), `Shop_Goop_Items_01` (Goopton), `Shop_Blank_Items_01` (Old Red) — exposed as `ItemBuilder.shopInventories[ShopType]` and `po.AddToSubShop(type, weight)`; Gunsling King table `gunslingkingshittyguntable`. Alexandria's `CustomShopController` mirrors this logic (also calls `GetRewardObjectShopStyle`) ([NPCAPI/CustomShopController.cs ~L511-540](https://github.com/Nevernamed22/Alexandria/blob/master/NPCAPI/CustomShopController.cs)); you can build an Isaac shop with `ShopAPI.SetUpShop(name, prefix, idleSprites, idleFps, talkSprites, talkFps, GenericLootTable lootTable, ShopCurrencyType currency, ... , addToMainNpcPool, percentChanceForMainPool, prerequisites, poolType, RainbowModeImmunity ...)` and a custom currency (`ShopAPI.AddCustomCurrencyType`).
- Other sources: `Dungeon.baseChestContents` (fallback when a LootData has no table), `LootEngine.GetItemOfTypeAndQuality<T>(quality, table, anyQuality)`, `LootEngine.DropItemWithoutInstantiating(GameObject item, Vector3 pos, Vector2 dir, float force, ...)` (drops an existing instance), `LootEngine.SpewLoot`, `RewardManager.SpawnTotallyRandomItem`.

### 4.2 Alexandria-provided hooks (preferred, no IL work) **[verified]** — [Misc/CustomActions.cs](https://github.com/Nevernamed22/Alexandria/blob/master/Misc/CustomActions.cs), [Misc/RoomRewardAPI.cs](https://github.com/Nevernamed22/Alexandria/blob/master/Misc/RoomRewardAPI.cs), [Misc/LootUtility.cs](https://github.com/Nevernamed22/Alexandria/blob/master/Misc/LootUtility.cs)

(IL hook into `RoomHandler.HandleRoomClearReward`.)
- `LootUtility.CreateLootTable()`, `table.AddItemToPool(id|PickupObject, weight)`, `AddItemsToPool(...)`, `po.RemovePickupFromLootTables()` (removes from both `GunsLootTable`/`ItemsLootTable`), `SelectByWeightNoExclusions()`.
- `ChestUtility.SpawnChestEasy(IntVector2, ChestTier, locked, GeneralChestType.ITEM|WEAPON, ...)` sets `chest.lootTable.lootTable` to Items/Guns table ([Misc/ChestUtility.cs](https://github.com/Nevernamed22/Alexandria/blob/master/Misc/ChestUtility.cs)).
- `DungeonHooks.OnPreDungeonGeneration(LoopDungeonGenerator, Dungeon, DungeonFlow, int seed)`, `OnPostDungeonGeneration`, `OnFoyerAwake` ([DungeonAPI/DungeonHooks.cs](https://github.com/Nevernamed22/Alexandria/blob/master/DungeonAPI/DungeonHooks.cs)).

### 4.3 Recommended Isaac-mode loot strategy **[inferred from the above]**
1. Build one `GenericLootTable IsaacItemsTable` (LootUtility) with all Isaac passives/actives (qualities D–S so the vanilla quality rolls still work).
2. When Isaac mode is active (checked per call via `GameManager.Instance.PrimaryPlayer.characterIdentity` or a static flag set in `CustomActions.OnRunStart`):
   - `[HarmonyPrefix] RewardManager.GetItemForPlayer(ref GenericLootTable tableToUse, ...)`: `if (tableToUse == rm.GunsLootTable || tableToUse == rm.ItemsLootTable) tableToUse = IsaacItemsTable;` — this single patch covers chests spawned via `SpawnInternal`, shop group‑2 slots, boss pedestals (`GetRewardObjectBossStyle`), `SpawnTotallyRandomItem`, and most mod code. (Jolly Coop and GungeonCraft call `GetItemForPlayer` directly, so they'd be covered too.) `LootData.GetItemForPlayer` is a *separate* implementation used by chests → also prefix `LootData.GetItemForPlayer(..., ref GenericLootTable tableToUse, ...)` or set `chest.lootTable.lootTable = IsaacItemsTable` in `CustomActions.OnChestPostSpawn`. GungeonCraft's debug patches show the chest hook shape: `[HarmonyPatch(typeof(Chest), nameof(Chest.DetermineContents))] static void Prefix(Chest __instance, PlayerController player, int tierShift){ __instance.forceContentIds = new(){id}; }` and `[HarmonyPatch(typeof(ShopItemController), nameof(ShopItemController.InitializeInternal))] static void Prefix(ShopItemController __instance, ref PickupObject i)` ([CwaffDebug.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/CwaffDebug.cs)).
   - Sub-shops (Trorc/Flynt/Cursula/Goopton/Old Red) draw group‑1 items from their own tables: either patch `BaseShopController.DoSetup` (BetterShop does a `[HarmonyPostfix]` on `ShopController`/`BaseShopController.DoSetup` to spawn extra `ShopItemController`s ([ShopGuaranteePatch.cs](https://github.com/appletree3232/BetterShop/blob/main/BetterShop/Patches/ShopGuaranteePatch.cs))), or filter in `CustomActions.OnShopItemStarted` by replacing gun items (`ForceOutOfStock()` + spawn replacement), or temporarily swap `shop.shopItems` in a `DoSetup` prefix.
   - Room clears: `RoomRewardAPI.OnRoomRewardDetermineContents` → push Isaac pickups (hearts/keys/coins/bombs) into `overrideItemPool`, or `overrideFunctionPool` for Isaac-style pedestal rooms.
   - Boss: `CustomActions.OnRewardPedestalDetermineContents` → fill `overrideItemPool` from the Isaac table (also sidesteps `IsBossRewardForcedGun`).
   - Safety net: `Gun.Pickup` prefix (Modular-style) or `GunInventory.AddGunToInventory` prefix returning `false` for non-starter guns, converting to an Isaac item drop.
3. Existing "game mode" mods for reference: GungeonCraft **Hecked Mode** (`HeckedMode.Hecked` enum, `_HeckedModeStatus`, IL patches on `Chest.RoomEntered`, `AIActor.CheckForBlackPhantomness`, etc., toggled via Gunfig) ([HeckedMode.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Misc/HeckedMode.cs)); vanilla's own `GameStatsManager.Instance.IsRainbowRun` + `GameManager.RainbowRunForceExcludedIDs/ForceIncludedIDs` (Rainbow mode is implemented as checks inside `LootData.GetItemForPlayer`, `Chest.SpewContentsOntoGround`, `BaseShopController.DoSetup` — a good model of how a run modifier threads through loot code); `GameManager.GameMode { NORMAL, SHORTCUT, BOSSRUSH, SUPERBOSSRUSH }` is an enum you should not extend. In-game toggle UI: **Gunfig** (`Gunfig.Get(modName).AddToggle(key, enabled, label, callback, updateType)`, `.Enabled(key)`, `AddScrollBox`, `AddButton`, `AddSubMenu`) ([GunfigAPI.cs](https://github.com/pcrain/Gunfig/blob/master/src/Gunfig/GunfigAPI.cs)). Persisting per-run data: GungeonCraft's `FakeItem`/`CwaffRunData` (an invisible passive item that gets mid-game-saved) ([SharedItemBehaviors.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/SharedItemBehaviors.cs), [CwaffRunData.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Misc/CwaffRunData.cs)).

## 5. Health: hearts/armor vs red/soul/black hearts **[verified vanilla, design inferred]**
- Vanilla: `HealthHaver` on the player: `GetCurrentHealth()/GetMaxHealth()` (floats, half-heart = 0.5), `float Armor { get; set; }` (setter blocked when `ForceZeroHealthState`), `ApplyHealing(float)`, `ApplyDamage(float damage, Vector2 dir, string source, CoreDamageTypes, DamageCategory, bool ignoreInvulnerabilityFrames, PixelCollider, bool ignoreDamageCaps)`, `SetHealthMaximum(float target, float? gain, bool keepPct)`, `ForceSetCurrentHealth`, `NextShotKills`, `NextDamageIgnoresArmor`, `minimumHealth`, events `OnDamaged(result,max,types,category,dir)`, `OnHealthChanged(result,max)`, `OnPreDeath`, `OnDeath`, `ModifyDamage : Action<HealthHaver, ModifyDamageEventArgs>` (fired before armor/health is applied — the hook GungeonCraft's Adrenaline Shot uses to intercept lethal damage; [AdrenalineShot.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Passives/AdrenalineShot.cs)), `ModifyHealing`, `TriggerInvulnerabilityPeriod`. Alexandria adds `PlayerOverrides.SetInvulnerable/SetImmuneToContactDamage(bool, reason)` and `ExtendedPlayerComponent.TriggerInvulnerableFrames`.
- Robot-style "armor only": `PlayerController.AllowZeroHealthState / ForceZeroHealthState` (CharApi `usesArmourNotHealth=true`); Alexandria IL-patches `ResetToFactorySettings`, `TriggerDarkSoulsReset`, `HandleCloneEffect`, `CoopResurrectInternal` so any `ForceZeroHealthState` character is treated like the Robot ([CharApiHooks.cs L28-66](https://github.com/Nevernamed22/Alexandria/blob/master/CharApi/Tools/CharApiHooks.cs)); StatAPI's `RecalculateStatsInternal` transpiler also keys off `AllowZeroHealthState`.
- HUD: `GameUIRoot.UpdatePlayerHealthUI(PlayerController, HealthHaver)` → `GameUIHeartController.UpdateHealth(HealthHaver)` renders `extantHearts` (`fullHeartSpriteName/halfHeartSpriteName/emptyHeartSpriteName` dfSprites) and `extantArmors` from `GetCurrentHealth/GetMaxHealth/Armor` ([GameUIHeartController.cs](https://github.com/fedes1to/EtG-source/blob/master/ExportedProject/Assets/MonoScript/Assembly-CSharp/GameUIHeartController.cs)). Custom HUD precedent: GungeonCraft Credit Card patches `GameUIRoot.UpdatePlayerConsumables` / `ShowCoreUI` postfix to recolor/replace the coin counter ([CreditCard.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Passives/CreditCard.cs)); Alexandria adds UI atlas sprites with `ToolsCharApi.AddUISprite(Texture2D|tk2dSpriteDefinition|resourcePath, name)` ([CharApi/Tools/Tools.cs](https://github.com/Nevernamed22/Alexandria/blob/master/CharApi/Tools/Tools.cs)).
- **No existing ETG mod implementing soul/black hearts was found** (GitHub code search for "soul heart" in C# ETG mods returned nothing; Thunderstore search found nothing). Simplest faithful mapping **[inferred]**: red hearts = `HealthHaver` health; **soul hearts = Armor** (armor already absorbs one hit per point and is lost before health, and vanilla's `Armor` pickup/`ArmorToGainOnInitialPickup` exists) — then re-skin the armor dfSprites (`armorSpritePrefab`, `damagedArmorAnimationPrefab`) to blue soul hearts via a `GameUIHeartController.UpdateHealth` postfix; black hearts would need a per-player counter component + `ModifyDamage` handler (consume black heart, trigger a blank-like `SilencerInstance` to mimic Necronomicon) + HUD postfix. Alternatively keep an entirely custom counter in a `MonoBehaviour` on the player, intercept damage in `HealthHaver.ModifyDamage` (set `args.ModifiedDamage = 0` and decrement your counter), and draw a custom HUD — but mind `NextShotKills`, `ReceivesTouchDamage`, and the Robot-special-casing above.

## 6. Sprites / assets / audio / strings pipeline **[verified]**
- Units: **16 px = 1 world unit** (`n = px/16`, 1px = 0.0625) ([pixel conversions](https://mtgmodders.gitbook.io/etg-modding-guide/making-a-gun/making-the-gun/creating-gun-jsons/pixel-measurement-conversions)); CharApi uses `tex.width/16f`, GungeonCraft `_TexelSize = 0.0625`, Alexandria docs say "1 is equal to 16 pixels". Item sprites rule of thumb ≤ 30×30 px; avoid pure black at sprite edges because the game auto-outlines ([sprite info](https://mtgmodders.gitbook.io/etg-modding-guide/all-things-spriting/important-sprite-creation-information.)). Perpendicularity/height: `AddSpriteToObjectPerpendicular`, `sprite.HeightOffGround`.
- Embedding: mark PNGs/`characterdata.txt`/`.bnk` as **Embedded Resource**; resource names become `RootNamespace.Folder.Sub.file.png`; Alexandria APIs take `"Namespace/Folder/name"` (slashes → dots, `.png` auto-added): `SpriteBuilder.SpriteFromResource(path, obj)`, `SpriteBuilder.AddSpriteToCollection(resourcePath, collection, name)` → sprite id; `ResourceExtractor.GetTextureFromResource(path.png)`, `GetTexturesFromResource(folder)`, `GetResourceNames()`, `ExtractEmbeddedResource`, `GetLinesFromEmbeddedResource` ([SpriteTools/ResourceExtractor.cs](https://github.com/Nevernamed22/Alexandria/blob/master/ItemAPI/SpriteTools/ResourceExtractor.cs), [gitbook loading sprites](https://mtgmodders.gitbook.io/etg-modding-guide/sprites/loading-custom-sprites)). Collections: `SpriteBuilder.itemCollection` (shared item collection, id 155's), `SpriteBuilder.ammonomiconCollection`, `SpriteBuilder.ConstructCollection(GameObject, name)` for your own, `SpriteBuilder.AddAnimation(animator, collection, spriteIds, clipName, wrapMode, fps)`.
- Faster alternative (GungeonCraft): pre-pack all PNGs into one atlas with "cheetah" and build `tk2dSpriteDefinition`s at load (`AtlasHelper`), or ship a Unity **2017.4.40** asset bundle with prebaked `tk2dSpriteCollectionData`/`tk2dSpriteAnimation` and use `Loader.BuildCharacterBundle` / `ItemBuilder.AddSpriteToObjectAssetbundle` / `GunInt.SetupSpritePrebaked` / `JsonEmbedder.EmbedJsonDataFromAssembly` ([gitbook asset bundles](https://mtgmodders.gitbook.io/etg-modding-guide/misc/making-asset-bundles); Modular ships `ModularSpriteProject.zip` as its Unity project). There is no Aseprite importer in Alexandria; the "newspritesetup" folder-of-PNG-frames convention is the intended export target (Aseprite → export frames per tag into folders named after the animation).
- Audio: `Alexandria.SoundAPI.SoundManager.LoadSoundbanksFromAssembly()` loads every embedded `*.bnk` (bank name = file name) ([SoundAPI/SoundManager.cs L237](https://github.com/Nevernamed22/Alexandria/blob/master/SoundAPI/SoundManager.cs)); play with `AkSoundEngine.PostEvent("Play_isaac_tear", gameObject)`. Banks are generated **without Wwise** by pcrain's Python script `gen-gungeon-audio-bank.py` (`python gen-gungeon-audio-bank.py -i wavs/ -o BankName [-s params.csv]`; CSV columns `volume, loops, channel(sound|music), limit`; WAV only) ([gungeon-modding-tools](https://raw.githubusercontent.com/pcrain/gungeon-modding-tools/master/gen-gungeon-audio-bank.py), [gitbook custom sounds](https://mtgmodders.gitbook.io/etg-modding-guide/sounds/using-custom-sounds)); the old Wwise route is documented as "(OUTDATED) Using Custom Sounds". Gun sound switch groups: `gun.gunSwitchGroup = "isaac_tears"; SoundManager.AddCustomSwitchData("WPN_Guns", gun.gunSwitchGroup, "Play_WPN_Gun_Shot_01", "Play_isaac_tear"); ... "Play_WPN_Gun_Reload_01", ...` ([gitbook gun sounds](https://mtgmodders.gitbook.io/etg-modding-guide/sounds/customising-gun-sounds)).
- Strings/localization: MTG API `ETGMod.Databases.Strings.{Core, Items, Enemies, Intro, Synergy, UI}` with `.Set(key, value)` / `.Set(GungeonSupportedLanguages lang, key, value)` / `SetComplex` ([StringDB.cs](https://github.com/SpecialAPI/ModTheGungeonAPI/blob/master/ModTheGungeonAPI/ETGMod/Databases/StringDB.cs)); item `SetName/SetShortDescription/SetLongDescription(lang, text)` overloads; CharApi `StringHandler.AddStringDefinition` for core table; Alexandria's `TranslationAPI` is in `_Deprecated/` (still compiled; `item.TranslateItemName(lang, text)` etc.). Text boxes: `TextBoxManager.ShowTextBox(...)` ([gitbook](https://mtgmodders.gitbook.io/etg-modding-guide/text-text-boxes-etc/textboxes)).
- Console commands for debugging: `ETGModConsole.Commands.AddGroup("isaac"); ETGModConsole.Commands.GetGroup("isaac").AddUnit("mode", args => ...)` ([Alexandria Misc/Commands.cs](https://github.com/Nevernamed22/Alexandria/blob/master/Misc/Commands.cs)).

## 7. Other game-mode levers / run hooks **[verified]**
- Run-start/level hooks: `CustomActions.OnRunStart` (Alexandria), `GameManager.Instance.OnNewLevelFullyLoaded` (event; GungeonCraft subscribes a one-shot handler inside a `Dungeon.FloorReached` postfix to get "first floor fully loaded" — see [CwaffEvents.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/Cwaff-Misc/CwaffEvents.cs), which also hooks `GameManager.LoadNextLevel/LoadCustomLevel` prefix for "BeforeRunStart", `GameManager.ClearActiveGameData` postfix for cleanup, and `FinalIntroSequenceManager.Start` for "all mods loaded"), `PlayerController.OnNewFloorLoaded`, `OnEnteredCombat`, `OnRoomClearEvent`, `OnReceivedDamage`, `OnKilledEnemy(Context)`, `PostProcessProjectile(Projectile, float)`, `OnUsedBlank`, `GunChanged`, `OnItemPurchased`, `OnRealPlayerDeath`; `DungeonHooks.OnPreDungeonGeneration` for seed/flow tweaks. Session check used by Alexandria/GungeonCraft: `GameStatsManager.Instance.GetSessionStatValue(TrackedStats.TIME_PLAYED) < 0.1f` ⇒ run just started.
- Start-item removal / loadout: CharApi `StripPlayer` + `HandleLoadout` already set `startingGunIds/startingPassiveItemIds/startingActiveItemIds` on the prefab; at runtime use Alexandria `player.RemoveItemFromInventory(PickupObject)`, `player.RemovePassiveItemAtIndex`, `player.IsStarterItem(id)`, `player.inventory.DestroyAllGuns()`.
- Blanks/keys/shells: `player.Blanks` (int), `player.carriedConsumables.Currency / KeyBullets`, `PlayerStats.NumBlanksPerFloor` and `StatType.AdditionalBlanksPerFloor`, `StatType.Curse/Coolness` (room-clear chest chance uses `Coolness/100 - Curse/100`; curse also drives Jammed spawns and LOTJ — `CustomActions.OnLOTJSpawned`).
- Breach merchants: Trorc/Goopton/Doug meta shops are `BaseShopController` with `baseShopType == AdditionalShopType.FOYER_META` reading `shopItems` and `encounterTrackable.prerequisites` (unlock blueprints); SaveAPI's `BreachShopTool.AddItemToTrorcMetaShop/AddItemToGooptonMetaShop/AddItemToDougMetaShop(po, cost)` adds unlockables (vendored copy in [GungeonCraft src/GungoSaveAPI/BreachShopTool.cs](https://github.com/pcrain/GungeonCraft/blob/master/src/GungoSaveAPI/BreachShopTool.cs)); Alexandria `BreachShopTools`/`ShopAPI.SetUpFoyerShop` place custom breach shops on `DungeonHooks.OnFoyerAwake`. Disabling in-run sub-shops entirely can be done by `ShopAPI.AddRoomToSubshopPool`-style table edits or by replacing stock in `OnShopItemStarted`; the sub-shop rooms come from `StaticReferences.subShopTable` (SharedInjectionData).
- Unlock/save: SaveAPI `AdvancedGameStatsManager.Instance.SetFlag(CustomDungeonFlags.X, true)`, `CustomDungeonPrerequisite` for `data.prerequisites`; vanilla `GameStatsManager.Instance.SetFlag/GetFlag(GungeonFlags)`, `SetCharacterSpecificFlag(PlayableCharacters, CharacterSpecificGungeonFlags, bool)`.

## Gaps / uncertainties
1. The gitbook "Creating A Standalone Custom Character" page only embeds a Google Doc (https://docs.google.com/document/d/135ntlWancU6Mw6o2fevZQVtaIEMWL8TNu9Hd8-Bgng4) that could not be fetched here; the folder/animation conventions above are taken directly from Alexandria's parser (`Loader.cs`, `SpriteHandler.playerAnimInfo`), which is authoritative but the doc may have extra tips (e.g., sprite sizes/offsets for `newspritesetup`).
2. Alexandria has **no wiki**; API docs are XML comments in source. Signatures above are from v0.5.10 (Aug 2026) — the `BuildCharacter` parameter list changed over versions (OMITB passes 15 args; enter-the-beyond example is older), so re-check against the installed NuGet version.
3. No ETG mod implementing soul/black hearts exists that I could find; Section 5 is a design proposal grounded in verified APIs, not a proven pattern.
4. `IsBossRewardForcedGun()` (gun forced when no new gun this floor) and `GunVersusItemPercentChance` are gun-biased assumptions baked into vanilla; with the `GetItemForPlayer` table-swap they become harmless (the Isaac table has no guns) but the "forced gun" log spam remains. Seeded runs use `GetItemForSeededRun`/`FloorRewardManifest.PregeneratedChestContents` (separate code path) — patch `GetItemForSeededRun` too if seeded Isaac runs matter.
5. Hiding the held gun sprite and the ammo HUD has no dedicated API; the approaches listed are inferred (transparent sprite / `ForceHandless` / `CustomAmmoDisplay`).
6. The decompiled source repo is a 2022 third-party dump of the final game version (2.1.9); method bodies are reliable but not an official source.
